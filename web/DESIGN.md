# 设计决定：出发看板

写页面前先看这一页。颜色、字号、间距一律用 `src/styles/tokens.less` 里的变量，不写裸色值。

## 为什么是"出发看板"

这个应用的核心画面是：谁付了钱、谁欠谁、多币别、按第几天分组。**最常被看的是金额和人名**，
所以风格取自机场和车站的信息看板：冷灰白底、深海军蓝页头、等宽数字，每个币别有一个固定的"线路色"，
扫一眼就能分清日元和港币。

候选里没选的两个：票根账本（偏装饰，暖白底是常见的"AI 默认"配色）、只改 Vant 主题色（没有记忆点）。

## 记忆点只放在两处，其余保持安静

1. **页头**：深海军蓝底 + 底部 3px 琥珀色信号线（`BoardHeader.vue`）。每个页面顶部都用。
2. **金额条**（行程页做的时候加 `CurrencyAmount.vue`）：币别色条 + 币别代码 + 等宽数字。

其它都用 Vant 原样的控件，靠主题变量调色，不重写组件。

## 色板

| 变量 | 值 | 用途 |
|---|---|---|
| `--tm-navy` | `#14283f` | 页头底色，也是正文文字色（不用纯黑） |
| `--tm-board` | `#eef1f5` | 页面底色 |
| `--tm-surface` | `#ffffff` | 卡片、输入框 |
| `--tm-line` | `#d5dbe3` | 分隔线（装饰，不承载信息） |
| `--tm-muted` | `#5b6778` | 次要文字 |
| `--tm-primary` | `#1b5ea8` | 主操作按钮、链接 |
| `--tm-amber` | `#f2a900` | 只用在深色页头上的强调 |
| `--tm-danger` | `#c62828` | 危险操作、错误 |

对比度已算过：正文 13:1，次要文字 ≥ 5:1，主按钮白字 6.5:1，琥珀对海军蓝 7.4:1。
币别色条对白底 ≥ 3.5:1（非文字元素要求 3:1）。

## 规则

- **颜色不是唯一线索。** 币别色条旁边一定写币别代码。"你欠"和"欠你"用文字和图形区分（实心标签 / 描边标签），
  不用红绿。（币别里日元是朱红，所以欠款不能再用红色表示，否则会混。）
- **数字用等宽。** 金额、币别代码、ID 加 `class="tm-num"`（IBM Plex Mono，自托管，拉丁子集 500/600，不走外网 CDN）。
  中文只用系统字体，不下载中文字体。
- **点击区域 ≥ 44px 高，相邻点击区之间 ≥ 8px。** 输入框正文 ≥ 16px（否则 iOS 聚焦会自动放大）。
- **圆角按层级：** 标签 4px、卡片和输入框 8px、底部弹层 16px。不是一个圆角刷全部。
- **间距是 4 的倍数**（`--tm-space-1…6`）；字号只用 12 / 14 / 16 / 18 / 24。
- **动效：** 只做"回应操作"的（按下反馈、展开、确认），不做页面进场动画。尊重 `prefers-reduced-motion`（`base.less` 已全局处理）。
- **图标：** 只用 Vant 自带图标，不再引入第二套。
- **两套版式，断点 960px**（`styles/breakpoints.less`，组件里 `@import (reference)` 后用 `@bp-desktop`）：
  - **< 960px（手机、平板竖屏）：** 单栏，最宽 480px 居中，两侧是深海军蓝。每页顶部是深色 `BoardHeader`。
    底部是导航条 `AppTabBar`（左"行程"，右"我的"，"我的"里有当前身份、切换身份、退出登录），
    **只在一级页面显示**：路由的 `meta.tab: true`（现在是首页和 `/me`）。详情、新建、编辑这些二级页面不显示，
    用页头里的"返回"；新增一级页面时给路由加 `meta.tab` 并在 `AppTabBar.vue` 里加一项（最多 5 项，图标和文字一起）。
  - **≥ 960px（PC）：** 顶部通栏导航条 `AppTopBar`（左：品牌和导航，右上角：头像 + 昵称，点开是菜单：昵称/ID、切换身份、退出登录；
    头像现在是空白用户图标 `user-o`，以后换真头像只改 `AppTopBar.vue` 里的 `.topbar__avatar`）。
    导航条下面是最宽 1120px 的内容区（`--tm-page-max`）；表单类页面用更窄的 560px（`tm-container--narrow`）。
    `BoardHeader` 在 PC 上退成内容区里的普通页面标题（不再画第二条深色带）。
  - 页面的 `<main>` 加 `class="tm-container"`（表单页再加 `tm-container--narrow`，并给 `BoardHeader` 传 `narrow`），
    左右留白和最大宽度都由它管；**页面自己的样式只设上下 padding**，否则会盖掉它。
  - 只在手机上出现的控件（比如首页页头里的"切换身份"按钮）在 PC 上用 `@media (min-width: @bp-desktop)` 隐藏，
    因为同样的功能已经在右上角头像菜单里。
  - 导航项现在只有"我的行程"，以后的页面往 `AppTopBar.vue` 的 `topbar__links` 里加。
  - 两套版式只是样式不同时用 CSS 媒体查询；**结构不同**时用 `useIsDesktop()`（`utils/media.ts`）切换，
    免得同一个列表在两套结构里各渲染一份、各请求一次。比如行程页：手机上是"支出 / 欠款 / 成员"三个标签
    （标签条吸顶，当前标签写在地址的 `?tab=` 里，"记一笔"固定在支出标签底部），PC 上是两栏
    （左边支出、"记一笔"在支出栏顶部，右边欠款和成员）。
- **按钮分主次，见下面「按钮」。**
- **错误文案：** 说明发生了什么、怎么办，不道歉、不含糊。统一走 `describeError`（`src/api/errors.ts`），表单字段错误挂在对应输入框下。

## 按钮

按钮的样式只表达"主次"和"危险"，同一种意思在所有页面长得一样。

- **每屏只有一个主按钮**（实心主色，`type="primary"`），是这一屏最常做的那件事：行程页的"记一笔"、表单页的提交。
  同一屏不出现第二个实心按钮。
- **次要操作用描边按钮或文字按钮。** 描边按钮写成 `size="small" plain type="primary" class="tm-button-secondary"`
  （`base.less` 里统一成 44px 高），同一屏的次要按钮尺寸一致（"添加成员""重试""返回行程"都是这一种）。
  文字按钮用于行内的小操作（比如"全选""清除日期"），同样保证 44px 的点击区。
- **危险操作（删除、移出成员、退出行程）不常驻页面。** 只出现在"⋯"菜单（`MoreMenu.vue`）或成员行的操作菜单里，
  菜单里这一项用危险色；点了之后还要过一次 `confirmAction` 确认（确认按钮也是危险色）。
- **深色页头上只放图标按钮或文字按钮**（白色），不放描边或实心按钮。页面级的更多操作统一放进页头右上角的
  "⋯"（`MoreMenu.vue`，点开是底部的操作菜单），菜单内容按身份生成（`utils/menus.ts`），没有可做的操作就不显示"⋯"。
  PC 上页头退成浅色标题区，同一个图标按钮变成深色。

## Vant 主题变量为什么写成 `html:root`

Vant 的组件样式是按需、较晚加载的，也在 `:root` 上声明默认值。同样的优先级下后加载的会覆盖我们的值
（实测按钮变回默认的亮蓝）。`html:root` 优先级更高，和加载顺序无关。

## 深色模式

这一版只做浅色，但所有颜色都走变量。以后加深色，只需要在 `tokens.less` 里补一套变量值，不用改组件。
